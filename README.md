# Scraper OS — Web Scraping Playbook

Interactive learning kit covering 3 scraping approaches, pipeline architecture, and project-specific use cases.

## Quick Start

```bash
npm install
npm run dev
```

## What's Inside

- **3 Approaches** — Static HTML (Cheerio), Browser Automation (Puppeteer/Playwright), API Reverse-Engineering
- **Pipeline** — 6-step flow from discovery to serving data
- **Your Apps** — Mapped scraping use cases across projects
- **Quick Start** — Universal scraper template + selector detective workflow

Built with React + Vite.
